# Private Submissions: Moved

Install the canonical package, then read `reference/encryption.md`.

Submission metadata and preview URLs are public. Sensitive bytes must be encrypted locally with the requester's published secp256k1 key before upload. An Ethereum address is not an encryption key. Do not use the incompatible historical `eth-crypto` envelope examples from older copies of this file.
