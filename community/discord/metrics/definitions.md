# Metrics definitions

Measure outcomes, not message volume.

- Onboarding completion: members completing rules and onboarding divided by eligible joins.
- First useful action: new members who view a task, open docs, create a valid support thread, or
  join a relevant builder channel within seven days.
- Useful-participation retention: members with a first useful action who complete another useful
  action 30 days later, reported only as an aggregate cohort rate.
- Support first response: staffed time from valid thread creation to first substantive response.
- Support resolution: threads with an accepted or staff-summarized resolution.
- Search deflection: members who view a matching resolved thread without opening a duplicate.
- Developer success: developer-help threads resolved with a reproducible answer or docs change.
- Safety incidence: confirmed scams, impersonation attempts, raids, and credential exposures.
- App reliability: signed interaction success rate, p95 response time, upstream failure rate, and
  public-data denial test results.

Do not optimize for raw member count, daily messages, or reaction volume. Review these measures
monthly with qualitative thread samples; publish only aggregated, non-identifying results.
