# Support triage

## Service levels

Owner: Community Lead. Backup: Support lead. Staffed hours: `{{SUPPORT_STAFFED_HOURS}}`.
Replace the staffed-hours provisioning token and publish the on-call escalation destination before
opening the public invite. Outside staffed hours, the private intake acknowledgement must state
when coverage resumes; it must not imply continuous monitoring.

- Safety, phishing, or active account compromise: acknowledge within 15 minutes while staffed.
- Payment or task-state blocker: acknowledge within 4 staffed hours.
- Product and developer support: acknowledge within one staffed business day.

## Flow

1. Confirm the thread contains no secrets or private task data; remove and escalate if it does.
2. Apply one problem tag and a state tag.
3. Reproduce from public information where possible.
4. Answer with a canonical documentation link or a concise verified workaround.
5. Move account-specific evidence to the private support system and post only the case reference.
6. Escalate confirmed bugs to the engineering tracker; do not promise a release date.
7. Mark the thread `resolved` and summarize the resolution for future searchers.

Discord support never asks a user to sign a transaction, transfer funds, reveal credentials, or
install remote-access software.
