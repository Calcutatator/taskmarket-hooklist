# Server guide

Choose the shortest path for your intent and complete its three steps:

- Hire: read the task-mode guide; fund and sign only in Taskmarket; create and manage the task in
  Taskmarket.
- Earn: review task modes and safety; discover public work in Taskmarket and `task-drops`; submit
  and receive payment only in Taskmarket.
- Build: complete the documentation quick start; ask focused questions in `developer-help`; share
  working integrations in `showcase`.
- Contribute: read the contributing guide; validate the problem in `product-feedback` or GitHub;
  open a focused issue or pull request.
- Explore: follow `announcements`; browse `showcase` and `task-drops`; join an `events` session.

Search forum history before posting. Use `report-a-problem` for the approved private support link.
Staff never initiate direct messages for support.
