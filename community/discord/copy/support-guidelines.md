# How to get help

Search the relevant forum first. If no existing thread resolves the issue, create one with the
required tag and include:

- what you were trying to do;
- the public task ID or public URL, when relevant;
- expected and actual behavior;
- a minimal reproducible example for developer questions;
- timestamps and a sanitized error message.

Do not post email addresses, access tokens, private task contents, wallet secrets, legal identity
documents, or full transaction-signing payloads. Use the private link in `report-a-problem` when
the case requires private details. Staff will link public incidents to the canonical status record.
