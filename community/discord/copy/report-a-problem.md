# Report a problem privately

Keep ordinary how-to questions in the public `support` forum so answers remain searchable.

For an account, payment, identity, scam, moderation, appeal, or dispute-mechanics case that requires
private details, use the approved intake at `{{PRIVATE_SUPPORT_URL}}`. For a suspected software
vulnerability, use the private GitHub security report at
<https://github.com/daydreamsai/taskmarket/security/advisories/new>.

`{{PRIVATE_SUPPORT_URL}}` is a provisioning token. Staff must replace it with the approved
authenticated intake before publishing this channel. Staff never initiate support in direct
messages and never request a seed phrase, private key, password, access token, or identity document
in Discord.
